# 干涉条纹簿：相位展开、支路切口与光学标定分支

本目录是领域离线案例包（非通用表格）。所有网格为 16×12 行主序。

## 目录结构
- `baseline/` — 基线七种不可覆盖输入：包裹相位(rad)、信噪评分(0..1)、无效遮罩(0/1)、
  波长(nm)、入射几何(deg, 反射双程)、标定面(nm, sample-plane 坐标基准)、切口编辑历史。
- `revisions/` — 一次参数修订（波长 632.8→635.0 nm）与一次局部源数据改动
  （质量图仅 (2,2)-(5,5) 区域重评分，携带 region）。
- `scenarios/<情形>/{minimal,combined}/` — 七个验收情形各自的最小输入与组合输入；
  两者共享的原始片段内容相同，存储层按内容哈希只存一份。
- `replay.json` — 重放记录：基线导入 → 展开 → 高度链 → 参数修订 → 局部源改动 →
  七个情形 → 冲突人工决定（局部锁定冲突 + 解决 + 撤销）。
- `case.json` — 案例元数据与领域规则清单。

## 领域规则（机器可读事件中的 rule 字段）
- `low-amplitude-no-guess`：低振幅区域不得猜相位，保持 unknown。
- `explicit-cut-offsets`：切口两侧的整周偏移显式表示。
- `keep-path-and-cycle-residuals`：不同展开树可得到局部一致解，保留路径与循环残差。

重放：`POST /api/case/load` 或在测试中以 `loadCasePack(store)` 执行。
