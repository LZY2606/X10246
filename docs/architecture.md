# 干涉条纹簿：长期复查架构

系统把原始输入、解释版本、派生结果和人工裁定分成不可变层。

- 原始片段按 SHA-256 去重；提交后只能追加父版本，不能覆盖。
- 每个派生结果都记录算法版本、参数指纹和直接来源版本。
- 查询实体时校验全部直接引用；引用缺失即判定档案损坏，不回退到最新版。
- 低振幅或无效像素保持 `unknown`，分支切口两侧的整周偏移以候选边显式保存。
- 多棵展开树分别保存路径、相位值和循环残差；无法唯一裁定时保留全部合法候选。
- 人工接受、拒绝、参数调整、锁定、冲突和撤销均写入追加事件链。
- 导出档案包含稳定身份、事件顺序、内容哈希和来源边；删除本地数据库后再导入仍可重建同一视图。

领域值保留原始单位和坐标基准；规范化结果只存在于派生层。无法转换的值保留原位并生成诊断，不会为绘图被静默丢弃。
